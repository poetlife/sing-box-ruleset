# Evolution Registry（持续进化索引）

本表是进化候选项跨周期状态的唯一信源。周期报告保存当时证据，设计/排障文档保存领域结论，外部系统保存协作状态；本表只维护它们之间的身份、链接与验证状态。

## 状态约定

`observed -> candidate -> accepted -> planned -> implemented -> validating -> validated | ineffective | inconclusive`

旁路终态：`dismissed`、`merged`。`inconclusive` 在数据补足后可回到 `validating`。
